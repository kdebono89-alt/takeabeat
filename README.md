# Take a Beat website

Published with GitHub Pages from main. Beta interest submissions use the existing Web3Forms account. Success is displayed only after service confirmation; failures retain the form. Signup details are retained for future beta invitations until opt-out, per Keith. See the public privacy section for provider and contact details.

The seven-slide full-width background carousel advances automatically every six seconds. Seven dots select individual images without stopping automatic playback. Playback resumes when the page becomes visible again; reduced-motion preferences disable the sliding animation. Lifestyle images are illustrative.
